# Approach

To complete this task, my plan is to use the following steps:

- Make any initial configuration changes such as:
  - using the ORM to retrieve persisted data.
  - fixing initial bugs.
- Implement business logic.
- Make UI improvements (this comes after the business logic in case the backend functionality impacts the way the data will be laid out in the client).
- Implement other optimizations.

# Pull Request Strategy

As often as I can, I prefer to use `main` as the base branch. Otherwise, I'll use a stacking strategy where foundational changes or non-breaking changes will be upstream. And, if possible, each PR will be atomic and testable (when relevant).
